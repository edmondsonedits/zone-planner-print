# Zone Planner

Open the [Zone Planner](https://edmondsonedits.github.io/zone-planner-print/) to plan and print an AE or Aerie schedule.

1. Use **Import** to open an existing Zone Planner backup or a staffing CSV or supported PDF. You can also add staff from the roster section.
2. Check the date and hours. Use **Schedule** to fill the active map, then review the assignments and coverage.
3. Choose **Print** to print the floor, coverage, or both. Choose **Save backup** to download an editable JSON file before you close the tab.

The public site starts with a blank roster. Imported staff data and edits stay in the current browser tab. Each person works with their own copy. Keep exports and printouts private when they contain employee information.

The website is static. GitHub Pages serves `index.html` and the bundled PDF reader. Open `index.html` through a local static server to preview changes before publishing. Use `main` at the repository root as the Pages source.
